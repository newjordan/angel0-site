Not another chat wrapper.
A cockpit for agents.

angel0 is a terminal-first coding and research cockpit where the ordinary terminal is the complete product surface — model and thinking controls, sandboxed tools, world-scale visual surfaces, telemetry, and a machine-readable task runner, in one Rust package.

What's new ↓ Architecture

What's new

Built different, on purpose.

Most agent tools bolt a model onto a REPL. angel0 starts from a different premise: the harness itself — routing, sandboxing, memory, verification, self-knowledge — is the product.

🛡️

Sandboxing as a first-class citizen

Every shell tool spawn is re-execed through a tiny dedicated angel-sandbox sibling binary with an explicit execution contract — not a shell escape afterthought. Workspace confinement is lexical and enforced at the path layer.

angel-sandbox · --sandbox-exec
🪞

A live self-model

The cockpit generates a map of its own source from the live tree every turn — module purposes, symbol outlines, build and test contracts — injected into its own context. It can reason about itself without a static, drifting ARCHITECTURE.md.

self_map · /self loop
📡

Telemetry that changes behavior

An experience ledger records every turn — hops, tokens, latency, cache-hit ratios — and the findings feed back into route calibration: cheapest-adequate model selection, spin-breaker tuning, hop budgets. Measurement closes the loop.

ledger.jsonl · calibration
🖥️

The terminal is the whole surface

No browser tab, no Electron shell. Ratatui renders the full cockpit — model controls, thinking budgets, world visuals (Scryglass, miniviz, image viewer) — inside the ordinary terminal, detached on demand for lean comp mode.

ratatui · zero-DOM
🤖

Agent-of-agents native

A fleet of OpenAI-compatible routes — local LAN seats, tailnet boxes, frontier APIs — is a first-class routing layer. Delegate, fan out panels, quorum-check answers, or drive one lane yourself. Without a key, the interactive cockpit falls back to an offline practice agent.

clubs · spawn · delegate
🧾

Machine-facing by contract

angel --task-json is a stable RL and competition entrypoint: exactly one result object on stdout, progress on stderr, explicit task and run IDs, hop and deadline limits, auditable rollout capture. The same binary humans drive is the one benchmarks grade.

--task-json · one result object
🌍

Worlds, not dashboards

Progress is spatial: a persistent realm with travel, arrival, and landmarks — a 3D realm, Scryglass scenes, a first-person miniviz — where verification and activity are visible as motion. The literal operation always leads the metaphor.

realm · miniviz · scryglass
🦀

Ship-speed Rust, no async runtime

The cockpit manifest depends on blocking HTTP with rustls, not an async runtime. The release profile is thin LTO, one codegen unit, and stripped symbols. Video stays behind a feature flag so a no-video build does not pay for it.

no async · thin LTO · 2 binaries
🧱

Safe self-modification rails

Because it can see its own source, it can improve it — under layered rails: workspace confinement, a hard gate on self-edits, and an always-available rollback path. The cockpit must never be able to brick itself.

confinement · hard gate · rollback

Architecture

One package, many surfaces.

A release build of the cockpit package produces angel plus its sibling angel-sandbox for cheap, confined tool spawns. The launcher at bin/angel0 builds and starts angel.

01 · drive

Human in the cockpit

Ratatui TUI: conversation, model and thinking controls, tool transcripts, slash surface, world panes. Lean comp mode detaches visuals for speed while every surface stays callable on demand.

02 · route

Club routing layer

OpenAI-compatible routes across LAN seats, tailnet fleet, and frontier APIs. Calibration data (hops-to-answer, input tokens per route) informs which club drives which class of task.

03 · act

Sandboxed tool plane

File edits, shell, code search, research tools — each spawn re-execed through angel-sandbox with explicit scope grants (read-only, write-paths). A denial is a permission failure, never a silent zero score.

04 · verify

Evidence-gated outcomes

Claims require verifier output. The competition runner grades read-only, from a fresh workspace, against resumable attempt ledgers — the cockpit can't grade its own homework.

05 · learn

Experience ledger and self-model

Every turn lands in the ledger; findings feed route calibration and breaker tuning. The self-model regenerates from the live tree, so the agent's map of itself can never go stale.

Run it

From a source checkout.

The interactive launcher builds the cockpit, then opens it. With no reachable route it falls back to the offline practice agent. Headless --task-json refuses that practice route unless you set ANGEL_PRACTICE=1; otherwise it exits with no_route. Use a fresh directory as the workspace.

# interactive cockpit, no-video build (portraits and images still included)
ANGEL_VIDEO=0 bin/angel0

# provider-free headless smoke: exactly one result object on stdout
smoke_workspace="$(mktemp -d)"
printf '%s\n' 'Return a short runner transport acknowledgement.' | \
ANGEL_PRACTICE=1 bin/angel0 --task-json \
  --driver practice \
  --workspace "$smoke_workspace" \
  --task-id transport-smoke \
  --run-id local-smoke-1 \
  --max-hops 2 \
  --deadline-secs 30 \
  --tool-profile essential
